# 철핑이 v1.0.0

철권8 매칭 화면에서 **상대와의 실제 회선 상태**를 측정해 알려주는 오버레이입니다.

게임이 보여주는 국가와 핑 칸은 매칭 서버가 계산한 값이라 실제와 다를 수 있습니다.
철핑이는 실제로 오가는 패킷을 직접 재서 **수락 버튼을 누르기 전에** 판단할 정보를 줍니다.

---

## 왜 필요한가

같은 "5칸"인데 실측은 이만큼 차이가 납니다.

| 게임 표시 | 실측 RTT | 실제 대전 |
|---|---|---|
| KR 5칸 | 5ms | 롤백 0~1f, 쾌적 |
| JP 5칸 | 36ms | 롤백 1~2f, 가끔 3f |
| SG 5칸 | ~80ms | 딜레이 1f + 롤백 2f 고정 |

핑 칸이 같아도 실제 체감은 전혀 다릅니다.
국가 설정를 바꾸면 국가 표시까지 바뀌기 때문에, 게임 화면만으로는 알 수 없습니다.

---

## 무엇을 보여주나

문제를 **두 종류로 나눠서** 보여줍니다. 원인이 다르면 체감이 다르기 때문입니다.

### 지연 — 상대가 얼마나 멀리 있는가

거리 때문에 생기는 지연입니다. 일정하게 무겁고 답답한 느낌으로 나타납니다.
예측은 가능해서 적응하면 플레이할 만합니다. (소위 말하는 핑)

### 안정 — 회선이 얼마나 고르게 오는가

거리가 가까워도 신호가 툭툭 끊기는 경우입니다.
언제 끊길지 모르기 때문에 콤보 실수가 늘어납니다.

> 평균 핑만으로는 두 번째를 절대 잡아낼 수 없습니다.
> 핑 60ms에 jitter 5ms인 상대와 핑 60ms에 jitter 45ms인 상대를,
> 게임은 똑같은 칸으로 표시합니다.

## 화면

**일반 모드** — 대전이 시작되면 자동으로 사라집니다.

```
BAD
지연  BAD    RTT 82ms      편도 2.5f
안정  BAD    stall 49/분   loss 3.9%
상대 #A7F2   ·   우클릭 메뉴
```

**컴팩트 모드** — 항상 떠 있고 대전 중에도 값이 갱신됩니다.

```
지연     안정     RTT
GOOD     WARN     36ms
```

창을 더블클릭하면 모드가 바뀝니다. 위치와 모드는 자동 저장됩니다.

## 측정 시간

| 시점 | 내용 |
|---|---|
| 매칭 후 1.5초 | 상대와 연결 수립, 측정 시작 |
| 3초 | 안정 값 표시 |
| 4~6초 | 지연 값 표시 |

위 측정 시간은 상대값이지만 최대 측성시간이며 로직 상 연결 시도 즉시 패킷이 수/발신 되므로
실제 계산 시간은 더 빠릅니다.

## 설치

### 1. Npcap 설치 (필수, 처음 한 번만)

https://npcap.com/#download 에서 Installer를 받아 설치합니다.

**설치 중 아래 세 옵션을 꼭 확인해 주세요.** 하나라도 틀리면 값이 표시되지 않습니다.

- ✅ `Install Npcap in WinPcap API-compatible Mode` — **체크**
- ⬜ `Support raw 802.11 traffic` — **해제**
- ⬜ `Restrict Npcap driver's access to Administrators only` — **해제**

설치 후 **재부팅**해 주세요.

### 2. 철핑이 실행

아래 zip을 받아 압축을 풀고 `철핑이.exe`를 실행합니다.

관리자 권한 요청 창이 뜨면 허용해 주세요. 지연(RTT) 측정에 필요합니다.

### 3. 게임 설정

철권8을 **전체 화면 창 모드**로 설정해 주세요.
전용 전체 화면에서는 오버레이가 보이지 않습니다.

> 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다.
> 서명 인증서가 없는 개인 제작 프로그램이라 나타나는 안내이며,
> `추가 정보` → `실행` 을 누르시면 됩니다.
> 서명은 돈이 들어요...ㅎㅎ

## 안전성

이 프로그램은 **게임을 전혀 건드리지 않습니다.**

| 하는 일 | 하지 않는 일 |
|---|---|
| 내 랜카드를 지나는 신호를 읽음 | 게임 메모리 읽기/쓰기 |
| 봉투 정보만 확인 (주소, 시각) | 게임 파일 수정 |
| 상대 주소로 표준 ping 발송 | 코드 주입 |
| 철권8 프로세스의 통신만 선별 | 입력 전송, 패킷 조작 |

게임 입장에서는 이 프로그램의 존재를 알 수 없습니다.

**상대 IP는 화면에 표시되지 않으며 기록으로도 남지 않습니다.**
방송이나 영상에 그대로 노출되어도 안전합니다.
화면의 `#A7F2` 형태 값은 같은 상대인지 구분하기 위한 것으로, 원래 주소를 되돌릴 수 없습니다.
저도 못 봅니다.

다만 게임 약관은 승인되지 않은 서드파티 소프트웨어를 포괄적으로 제한하는 경우가 많고,
최종 판단은 게임사가 합니다. **사용 여부는 각자 판단하에 결정해 주세요.**

## 알아두실 점

- **측정에는 내 회선 상태도 반영됩니다.** 내가 와이파이를 쓰면 상대가 멀쩡해도 안정 값이 나쁘게 나올 수 있습니다.
- **판정 기준은 아직 표본이 적습니다.** 실제 대전 데이터로 정했지만 수십 판 수준이라 앞으로 조정될 수 있습니다.
- **상대가 ping을 차단하면** RTT 앞에 `~` 가 붙습니다. 경로상 가장 가까운 지점까지 잰 추정값이며 실제보다 5~10ms 작게 나옵니다. 대부분의 공유기가 기본적으로 차단하기 때문에 흔하게 발생합니다.

## 피드백 진짜 많이 필요함

기준값을 다듬는 데 실사용 경험이 가장 중요합니다.

- "BAD가 떴는데 해 보니 괜찮았다"
- "GOOD인데 렉이 심했다"

이런 제보를 Issues나 갤 작성글에 남겨주세요.
가능하면 **게임 내 딜레이/롤백 프레임 표시**를 함께 알려 주시면 더 정확하게 반영할 수 있습니다.
